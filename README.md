# 📊 SBTET Attendance Integration

Campus Bridge keeps the existing **Attendance Management** feature and connects it with the official SBTET Telangana Student Attendance page:

**SBTET Student Attendance:**
https://www.sbtet.telangana.gov.in/app/views/Examssite/StudentAttendance.html

The SBTET attendance page requires the student's **PIN number and CAPTCHA** before attendance information is retrieved. The integration should therefore respect the SBTET authentication/CAPTCHA mechanism and should not attempt to bypass the CAPTCHA.
